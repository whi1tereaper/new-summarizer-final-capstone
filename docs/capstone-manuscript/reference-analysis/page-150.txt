      2) Upload File















       •   You have the option to upload Files or
           Folders.
       •   Select a file or folder to upload, or drag it
           and drop it into the system.
       •   Click “Upload Files” or “Upload Folders” to
           upload them.
       •   Wait for the Files or Folders to be uploaded.

       •   The uploaded folder or file will then be
           displayed.

           name, a modal will be displayed with the
           options to Cancel, Replace, or Keep Both.
