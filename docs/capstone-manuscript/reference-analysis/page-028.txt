Cloud-based document systems are used because
they allow unified upload, download, sharing,
auditing, retrieval, and role setting while
improving scalability and reducing operational
costs (Han et al., 2021; Sipahutar et al., 2025).
A secured cloud-based EDMS for a university
records  unit  used AES  encryption and  was
reported to be effective in storing, retrieving,
and sharing documents securely (Justina et al.,
2022). More recent intelligent document systems
extend these features with OCR, semantic search,
automated metadata extraction, audit logging,
and  policy-based  retention  to  strengthen
compliance readiness and reduce manual handling
time (Chode, 2025).
