   Figure 11    presents the Level 2 Data Flow
Diagram (DFD) for the Profile Management process
of the AccredX: Record Management and Archiving
System.   This   process   allows   both   the
Administrator and Compliance Manager to view and
maintain their personal account information
through the Users (D1) data store.
   The process begins with         3.1 Fetch Profile
Metadata,    where the user requests access to
their profile information. The system retrieves
the relevant account details from the Users (D1)
database,  including  personal  information,
account settings, and role-related data. The
retrieved information is then displayed to the
user for viewing and verification.
   The  3.2 Update Profile Info process enables
users to modify their profile details whenever
necessary. Information such as name, contact
details, username, and other authorized profile
attributes may be updated through this process.
Once the modifications are submitted, the system
validates  the  changes  and  updates  the
corresponding records in the Users (D1) database
to ensure that user information remains accurate
and current.
