## Abstract

LIGHT summarizer is a web application intended to assist users in reviewing lengthy written material through configurable summaries and related reading functions. The researcher-supplied draft identifies students of Nueva Ecija University of Science and Technology, Peñaranda Off-Campus, as intended users and describes an Agile development approach. These statements provide project context; completed institutional research activities and participant evaluation records were not supplied. This manuscript therefore reports the inspected implementation and reproducible technical evidence while presenting the human-evaluation design as proposed.

The technical examination covered PHP application logic, the Python processing engine, public interfaces, database definitions, configuration and operational scripts. Direct metadata queries verified 31 tables, 312 columns and 35 foreign keys in the configured MariaDB database without reading application records. Source inspection identified text, URL, PDF and DOCX input paths; configurable summary modes, depth and presentation; history, feedback, translation, audio, administration and a separate evaluation subsystem. Selected behavior was examined through isolated synthetic fixtures and source-preserving interface rendering.

The evidence establishes implemented workflows and specific limitations. Isolated tests reproduced missing ownership checks in the document API and incorrect suffix-byte audio delivery. Additional findings include password-reset schema drift, incomplete persistent-token revocation, an alternate administrator status path that bypasses safeguards, and text cleaning that can reject ordinary prose. These findings prevent an unqualified claim of deployment readiness. The manuscript provides corrected architecture documentation, a complete data dictionary, user and maintenance manuals, and proposed technical and end-user instruments. No respondent counts, questionnaire means, acceptance ratings, learning gains or time savings are asserted. Human assessment and institutional completion remain necessary before conclusions about educational usefulness or user acceptance can be drawn.

Keywords: article summarization; natural language processing; software audit; source fidelity; evaluation design; LIGHT summarizer.
