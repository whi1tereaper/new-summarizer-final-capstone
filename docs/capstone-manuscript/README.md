# LIGHT summarizer manuscript package

Open [the editable Word manuscript](EDITABLE_MANUSCRIPT.docx) or [the PDF preview](EDITABLE_MANUSCRIPT.pdf). Start review with the [documentation readiness report](DOCUMENTATION_READINESS_REPORT.md), then resolve the [research information register](RESEARCH_INFORMATION_NEEDED.md).

This is a complete technical documentation foundation with clearly marked research gaps. It is not an approved final capstone submission. Genuine respondent results, institutional approvals and missing project particulars must be supplied before those sections can be finalized.

The [system audit](../system-audit/COMPLETE_SYSTEM_AUDIT.md) provides source and test evidence. [Appendix F](APPENDIX_F_USER_MANUAL.md) explains user actions; [Appendix G](APPENDIX_G_MAINTENANCE_MANUAL.md) explains operational requirements and limitations. The [build guide](build/README.md) describes how to regenerate the editable document and refresh its fields.

The `reference-analysis/` directory contains local working extracts of the supplied reference and researcher draft, including personal/institutional material from those sources. They support the local comparison and are not part of the generated manuscript. Share the intended final deliverables and selected evidence deliberately; do not treat the entire working directory as the submission package.
